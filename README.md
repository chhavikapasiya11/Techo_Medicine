## Techomedicine 🩺

Techomedicine is a secure, scalable telemedicine platform that enables digital healthcare delivery through seamless doctor–patient interactions. It centralizes appointment scheduling, electronic medical records, and AI-powered assistance using the Gemini API into a single system.

## 🌟 Features

### Core Features

• Unified telemedicine system for appointments, patient management, and AI assistance

• Smart appointment scheduling for booking, rescheduling, and tracking consultations

• Secure doctor–patient communication with authenticated access

• AI-powered assistance using Gemini API for healthcare queries

• Role-based authentication for doctors and patients using JWT

• Data privacy and encrypted storage for patient information


### Additional Features

• Separate dashboards for doctors and patients

• Jitsi meet integration for online appointment

• Scalable backend architecture

## 🛠 Tech Stack

• Frontend: React.js, HTML,CSS

• Backend: Node.js, Express.js

• Database: MongoDB 

• Authentication: JWT

• AI: Gemini API

• Communication: jitsi-meet

## ⚙️ Installation

### Clone the repository
```bash
https://github.com/chhavikapasiya11/Techo_Medicine.git
cd Techo_Medicine
```

### Run locally

#### Backend
```bash
cd backend
npm install
node index.js
```

#### Frontend
```bash
cd ../frontend
npm install
npm start
```
